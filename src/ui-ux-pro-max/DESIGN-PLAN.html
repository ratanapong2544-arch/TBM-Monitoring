01เป้าหมาย & ขอบเขต

เปลี่ยน "ผิว" (visual language) ของทั้งแอปให้เป็น CMI AI Mark 2 (TEAM Navy / IBM Plex / corporate enterprise) โดย ไม่กระทบการทำงานเดิมแม้แต่น้อย

ระดับงาน: B — Reskin เต็ม + ปรับ Shell (header / nav / layout) ให้เป็น enterprise dashboard

🔒 ข้อจำกัดเด็ดขาด — ต้องเหมือนเดิม 100%
ห้ามกระทบรายละเอียด
Data flow / StatecurrentModule, activeTab, groutRecords, segmentRecords, shiftReports, props ทุกตัว
การกรอกข้อมูลทุก input / select / textarea / slider / file-upload + validation + auto-link
การคำนวณsoil volume, ratio, CH, ring offset, cumulative, delay — ทุก formula
APIGAS_URL + apiCall + Gemini summary
กราฟ (charts)recharts ทุกตัว: โครงสร้าง, dataKey, แกน, logic — เปลี่ยนได้แค่ สี
ตารางแสดงเวลาการทำงานwork-time table (ShiftReport): hour-cell grid + activity bars
หน้าสรุป (summary)Overview, Report, ExecutiveDashboard — ตัวเลข/โครงเดิม
Exporthtml2canvas → JPG + window.print() → PDF + @media print

หลักการ

  • Presentational-only: แตะแค่ className, CSS, shell layout, wrapper — ไม่แตะ logic
  • Token-driven: CMI Mark 2 tokens = single source of truth
  • โครงสร้าง DOM/props เดิม: เพื่อให้ export (html2canvas อิง DOM tree) ไม่พัง
  • ใช้เฉพาะที่จำเป็น จาก design system — ส่วนที่แอปไม่มีไม่เอามา

04สถาปัตยกรรมโค้ด

4.1 โครงสร้าง src/ui-ux-pro-max/

src/ui-ux-pro-max/
├── DESIGN-PLAN.md / .html      ← เอกสารนี้
├── tokens.css                  ← @font-face + :root CSS variables
├── fonts/                      ← IBM Plex *.ttf (self-hosted)
├── assets/                     ← cmi-mark.svg, team-group-logo.svg
├── theme/cmiTailwindTheme.js   ← token mapping → tailwind.config.js
├── chartTheme.js               ← CMI recharts palette + helper
├── components/
│   ├── Shell · Sidebar · TopBar · BottomNav · MoreSheet
│   ├── StickyActionBar · Card · StatCard · Badge · Button · SegmentedToggle
│   └── index.js
└── index.js

4.2 วิธี bridge Tailwind ↔ CMI

  • tokens.css ประกาศ @font-face + :root{--color-navy…} → import ใน src/index.tsx
  • tailwind.config.js extend ด้วย cmiTailwindTheme.js → ได้ bg-navy, rounded-card, shadow-card, font-sans=IBM Plex ฯลฯ
  • แก้ className ใน views ทีละหน้า: bg-blue-600→bg-navy, rounded-3xl→rounded-card, font-black→font-semibold

4.3 หลักการแก้ไฟล์

  • Generic primitives (Card, Badge, Button, nav) → อยู่ใน ui-ux-pro-max/
  • Domain components (RingVisualizer) → คงที่เดิม แค่ recolor
  • Views → แก้ในที่เดิม เปลี่ยน className + import primitives — โครง JSX/props เดิม

5.2 Mobile (< lg) — Docked Bottom Nav

  • 5 ปุ่ม: Home · Record · Dashboard · Shift · More
  • More → bottom sheet: Data Log·Segment/Grout, Stats Report (กลุ่ม/ชื่อตรงกับ sidebar)
  • Record / Data Log → SegmentedToggle [Segment | Grout] ในหน้า (logic เดิม)
🔑 กติกาแก้ปัญหา nav บังเนื้อหา (ปัญหาหลักที่ระบุ)
  1. Docked ชิดขอบล่าง (ไม่ลอย) เต็มกว้าง — content เว้น padding-bottom = nav + safe-area
  2. เคารพ env(safe-area-inset-bottom) (home indicator / gesture bar) ทุกหน้า
  3. ปุ่มหลัก (บันทึก) = StickyActionBar เหนือ nav เสมอ — กดได้ตลอด ไม่โดนทับ
  4. คีย์บอร์ดเด้ง → nav ซ่อนชั่วคราว
  5. (ออปชั่น) ตาราง/รายงานยาว → nav auto-hide ตอนเลื่อนลง

07จุดเสี่ยงสูง & การรักษา (verified จากโค้ดจริง)

7.1 Export — ReportView + ShiftReportView
กลไก: loadHtml2Canvas() → html2canvas(el,{onclone}) → toDataURL("image/jpeg",0.9) → link.download=*.jpg → .click() (Report:181-209, Shift:205-233). onclone แทนค่า input ผ่าน data-html2canvas-id.
กฎ: คง id container (#shift-report-container), โครง DOM, print: classes, โครง <input> จริง — แตะแค่ className
7.2 Print — window.print() + @media print
window.print() (Report:341, Shift:198, Exec:22/801) + @media print ใน globals.css (A4, scale 0.88, input→dotted).
กฎ: คง @media print + print:* + .no-print · navy header/sidebar ต้องมี print:hidden ครบ
7.3 Work-time table — ShiftReportView
getBarColorClasses() (187-191): bg-stripe-blue/red/green (Main/Delay/Service) นิยามใน globals.css · ตาราง table-fixed min-w-[800px] + activity bar absolute.
แผน: เปลี่ยน stripe เป็นโทน CMI (navy / Code-D / Code-A) แต่ คง 3 ความหมาย + grid/bar positioning + print:border-black
7.4 Charts — ExecutiveDashboardView
สี hardcode เป็น hex จำนวนมากใน props (fill=, stroke=, <Cell>, SHIFT_COLORS:587, legend:906-907).
แผน: ย้ายสีทั้งหมดไป chartTheme.js แล้วอ้างอิง — คง dataKey/แกน/ReferenceLine/logic เดิม (semantic-aware §3.2)
7.5 RingVisualizer SVG
recolor hatch/stroke เท่านั้น — คง geometry / rotation / onClick

10นอกขอบเขต (YAGNI)
